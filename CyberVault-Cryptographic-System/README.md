# CyberVault: Secure File Encryption and Digital Signature System

A secure file protection system using modern cryptographic techniques to ensure data confidentiality, integrity, and authenticity.

## Features Demonstrated
* **Symmetric Encryption:** File encryption and decryption using AES and DES algorithms.
* **Asymmetric Encryption & Key Exchange:** Secure session key wrapping via RSA.
* **Digital Signatures:** Authenticity verification using DSA[cite: 1].
* **Integrity Hashing:** Tamper detection using SHA-256 fingerprints[cite: 1].
* **Defensive Mechanisms:** Rate-limiting login portals for brute force protection[cite: 1].
* **Audit Trails:** Secure logging of all security actions and events[cite: 1].

## Performance Analysis
Includes a benchmarking study evaluating the computational speed and efficiency trade-offs between AES-256-CBC and legacy DES-CBC standards[cite: 1].
